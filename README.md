## Introduction

This repository contains a demo of the localization and decoding pipeline for the paper "SCRMark: Screen-Camera Robust Watermarking for Arbitrary Display Content". 

The pre-trained weights for the segmentation-based locator can be downloaded from: 
"https://pan.quark.cn/s/0f2350e574aa"

Place the downloaded file into the "weights" folder.

The complete official PyTorch implementation will be made available as soon as the paper is accepted.
